# Recordings

Record, transcribe, and paste into the apps you use.

[Download Recordings](https://recordings.md) · [Report a bug](https://github.com/hasna/recordings/issues/new?template=bug_report.yml) · [Suggest a feature](https://github.com/hasna/recordings/issues/new?template=feature_request.yml)

This is the public feedback and updates hub for Recordings for macOS.

## Feedback

Search [existing issues](https://github.com/hasna/recordings/issues) before opening a new one. Include your app version, macOS version, whether you use local or cloud transcription, and the steps needed to reproduce the problem.

Issues are public. Please leave out private recordings, transcripts, account details, and credentials.

## Updates

Follow [Releases](https://github.com/hasna/recordings/releases) for release notes. To receive updates on GitHub, choose **Watch → Custom → Releases**.

Get the app from [recordings.md](https://recordings.md). Installed copies can check for updates from the Recordings menu.
